Quiet stretch on the site itself. One change worth writing down, and it's about
how links to the site look when they get pasted somewhere else.

Posts with a cover image already get their own share card, the preview picture
that chat apps and social sites show next to a link. Everything else falls back
to a default card. That default is now a full-bleed 1200x630 image, which is the
size those previews are built around, so the picture fills the frame.

The page head also says more about the image. It declares the card's width and
height, so whatever is building the preview knows the dimensions up front, and it
carries alt text, so the image has a description for anyone who isn't looking at
it.
