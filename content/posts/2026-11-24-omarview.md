I wanted Mission Control on this laptop. Every workspace on one screen,
the windows where they actually sit, and a way to jump to one. F3, or
the top-right corner, which is where my hand already goes.

![Omarview open on this laptop. Three workspaces in a row, the middle one selected.](/img/omarview.webp)

Omarchy runs on Hyprland. The usual way to draw that overview is a
plugin that hooks the compositor's render path, where Hyprland draws
each frame. Those hooks only exist on x86_64. On anything else the hook
function returns false and the plugin never starts. This laptop is ARM.
I tried it. It didn't start.

The shell was already in the session, drawing the bar. It can ask
Hyprland for the workspaces and the windows, and Hyprland will hand
over a picture of a window without any render hook. So I wrote the
overview there.

The pictures didn't move.

Hyprland will keep sending new frames. It only sends the next one when
the monitor itself redraws. The overview covers the screen and then
sits still, so the monitor has nothing new to do, and every tile stays
on the first frame. I put a video on and opened the view. The video
froze with everything else. So did the window I had just been typing
in.

A covered window also stops painting. As far as the program is
concerned it is no longer on screen, so it waits. Copying it again
just copies the same picture.

While the overview is open I tell every window to keep drawing.
Hyprland already has a flag for that, the one people use when they
want to capture a window that isn't focused. I also flip a single
pixel in the overlay on a timer, so the monitor commits and the next
frame has a reason to show up. Close the view and both of those stop.
Windows go back to drawing only when they're actually visible.

Some programs still won't. If an app decides it is hidden and refuses
to paint, the tile holds the last frame it did paint.

Each tile is a full-size copy of that window for as long as the
overview is up. Closing it ends the copies.

Omarview is that plugin. The view is QML, the markup the shell is
already written in, plus a short script for the corner. Apache 2.0, at
[ergofobe/omarview](https://github.com/ergofobe/omarview).
